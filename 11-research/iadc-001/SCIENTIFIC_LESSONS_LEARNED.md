# Scientific Lessons Learned

1. Timestamp equality is not calendar-date equality; the prior loader silently erased all yield
   and policy observations and therefore invalidated macro inference.
2. Nominal yields are not real yields. Substitution would create an unsupported mechanism claim.
3. A daily short-rate proxy is not an FOMC surprise series.
4. Multiple comparisons create abundant apparent alpha; independent temporal and placebo gates
   must follow false-discovery control.
5. Stable association does not establish causality or portfolio value.
